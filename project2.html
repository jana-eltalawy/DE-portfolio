Holo_Process
Advanced Image Processing

A comprehensive web-based image processing application featuring client-side and server-side processing, along with advanced color blindness simulation and correction tools.

Key Features

  • Core Image Processing: Grayscale, Sepia, Invert filters, brightness/contrast/saturation adjustments, gamma correction.
  • Geometric Transforms: Rotation, translation, shearing.
  • Convolution Filters: Blur, Sharpen, Edge Detection, Emboss.
  • Morphological Operations: Erosion, Dilation.
  • Advanced Effects: Histogram Equalization, Cartoon Filter, Noise Addition.
  • Color Blindness Accessibility: Simulation for Protanopia, Deuteranopia, Tritanopia; Daltonization correction to enhance lost color info; educational tooltips for awareness.

Project Goal

Holo_Process aims to provide a complete image processing toolkit that not only performs standard image edits and transformations, but also addresses color accessibility for users with color vision deficiencies, helping designers and educators create more inclusive content.

Tools & Technologies

  • Python: Server-side image processing, advanced filters, gamma correction, and morphological operations.
  • JavaScript: Client-side image manipulation and interactive UI features.
  • HTML/CSS: Responsive web interface for desktop and mobile.
  • OpenCV: Image processing and analysis.
  • Color Accessibility Algorithms: Simulation and Daltonization correction.
