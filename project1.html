Object Detection
Using YOLOv8

A web-based real-time object detection system built using YOLOv8 and Flask, supporting live webcam streaming and image upload.

🔹 Implemented YOLOv8 for fast and accurate real-time object detection
🔹 Built a Flask-based backend to deploy the AI model on the web
🔹 Integrated webcam streaming and image upload functionality
🔹 Designed a clean and beginner-friendly user interface

Project Description

This project focuses on building a real-time object detection system using the YOLOv8 deep learning model and deploying it through a web application powered by Flask. The application allows users to upload images or use their device’s webcam to detect objects instantly.

The project combines computer vision, backend development, and frontend design to demonstrate how AI models can be integrated into real-world web applications.

  • Load and run a pretrained YOLOv8 model for object detection
  • Process images and video frames using OpenCV
  • Display bounding boxes and class labels in real time
  • Handle client requests through a Flask-based API

This project highlights my ability to deploy AI models, work with live video streams, and build end-to-end intelligent web applications.
