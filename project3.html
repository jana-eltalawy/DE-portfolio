Car Agency Management System

A comprehensive relational database system for managing car sales, rentals, employees, clients, and accessories. Implemented using SQL Server with tables, views, stored procedures, and triggers to automate business processes.

Project Overview

The Car Agency Management System was designed to streamline operations for a car sales and rental business. It tracks vehicle inventory, client information, employee details, rental and sales transactions, maintenance, and accessory sales. Key functionalities include relational data management, reporting via views, and process automation using stored procedures and triggers.

Core Features

  • Relational tables for Employees, Clients, Cars, Rentals, Sales, Maintenance, Accessories, and Customer Evaluations.
  • Views to quickly access available rental cars, active employees, and cars under maintenance.
  • Stored procedures to fetch sales per employee and client rental history.
  • Triggers to automatically update car status after rental or sale and maintain stock integrity for accessories.
  • Transactional control to ensure consistency in accessory stock management.

Tools & Technologies

  • SQL Server: Database creation, table management, queries, views, stored procedures, and triggers.
  • T-SQL: Advanced querying, transactional operations, and constraints implementation.
  • Database Design: Normalization, relationships, primary & foreign keys, and integrity constraints.
